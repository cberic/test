# Install the LsqFit.jl package

The package is used for the Murnaghan equation of state fitting based on the energy-volume data to compute pressure. 

In your terminal, type `julia`, which will open the julia REPL, and and in the PEPL, type

```julia
using Pkg
Pkg.add("LsqFit")
```

The installation of the LsqFit package may take a while. After installing the LsqFit package, run the following command to test if it is working:

```julia
using LsqFit  # this may take >1 minute to load

xdata = [ 1.0
        0.9410359787896052
        0.892747272010167
        0.8440028046803102
        0.7944607563872212
        0.768315877119944
        0.7444147421008809]

ydata = [ 0.0
        0.002892932000008841

p0 = [0.0, 5.0, 0.0]

@. model(x, p) = (p[1]/p[2])*x^(-p[2]) + (p[1]-p[3])*x
```

# Run XP-PCM calculations

Copy `xppcm-atom.jl` and `Li.jl` to a working folder. Modify the input file `Li.jl` according to the instructions in the file. You may change the name of the input file.

Make sure Gaussian09 or Gaussian16 is properly installed, and `g09` or `g16` will actually call the program. The script will use `g16` over `g09` if both are installed.

Then run the following command (4 cpu cores/threads are assigned) to start the XP-PCM calculation:

```bash
julia --threads 4 xppcm-atom.jl Li.jl
```

Below is an example PBS script for running XP-PCM calculations on a cluster. Modify the PBS script according your cluster specifications. Important thing is to let the computing node know the paths to `g09`/`g16` and `julia`.

```pbs
#!/bin/bash
#PBS -q parallel
#PBS -l nodes=1:ppn=24
#PBS -l mem=48gb
#PBS -l cput=24:00:00 
#PBS -N xppcm

cd $PBS_O_WORKDIR

module load Gaussian/16

/scratch/user/julia-1.8.5/bin/julia --threads 24 xppcm-atom.jl Li.jl
```

# Understand the output

When the calculation starts, the script will first compute the volume of the atom (Vc), as a sphere, based on the assigned radius, for every scaling factor (f). Then, the volume ratio Vc(f)/Vc(f=1.2) will be used to determine the solvent properties at every scaling factor. With these solvent properties, a Gaussian job will be run to calculate the XP-PCM electronic energies (Ger) for scaling factor.

When the calculation is done, the XP-PCM data will be printed to the `filename-properties.dat` file in the working directory. Below shows the structure of a working folder

```
├── xppcm.jl                   # XP-PCM script
├── Li.jl                      # XP-PCM input for Li
├── Li-Ger.gjf                 # Gaussian input
├── Li-Ger.chk                 # Gaussian chekpoint file
├── Li-Ger.log                 # Gaussian output
├── Li-properties.dat          # XP-PCM output for Li
└── other files                # Other (unimportant) files generated by Gaussian
```

Below shows the `Li-properties.dat` file of an XP-PCM calculations on Li. If some of the symbols are not displayed correctly, consider using JuliaMono  (https://juliamono.netlify.app) or other Unicode-compatible font for your text editor.

- 𝑓 is the scaling factor for the vdW radii
- 𝑉𝑐 is the cavity volume of the molecule
- 𝑠 is the linear scaling factor
- 𝜀, and 𝜌ₛₒₗ are solvent properties
- 𝐸𝑔𝑎𝑠 is gas phase energy with the solvent-field-modified wave function
- 𝐸ₑₗₑₛₜₐₜ is the electrostatic interaction (polarization) energy between the molecule and the solvent of the PCM model
- 𝐸ₚₐᵤₗᵢ is the Pauli repulsion energy between the molecule and the solvent
- 𝐺𝑒𝑟 is the total XP-PCM electronic energy, the sum of previous three terms
- 𝑝 is the pressure
